HUON PRINTS WEBSITE — START HERE

1. Double-click index.html to preview your website in a browser.
2. To change products, edit the products array near the top of script.js.
   Set price:null for products requiring a quote.
3. Replace the emoji product placeholders with your real product photos before launch.
4. In index.html, replace BOTH https://www.facebook.com/ links with your actual Huon Prints Facebook page URL.
5. Review all wording, pricing, availability, product safety information, and ordering terms before publishing.
6. Upload the contents of this folder to a static hosting provider such as Netlify or Cloudflare Pages. You can use their free starter hosting where eligible.
7. This version has no payment processing or backend. Customers copy an order summary and send it through Facebook Messenger. No order is placed automatically.

Note: Product names and prices are examples. The shop is a functional starter prototype, not a live store.
