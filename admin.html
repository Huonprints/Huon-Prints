How to save your changes

Use the new Upload catalogue and Upload photographs shortcuts above. Both open the GitHub review branch upload screen. Upload catalogue.js to the repository root, and product images to assets/products. If Chrome adds (1) to catalogue.js, rename it back to catalogue.js first. GitHub still requires you to select files and commit changes manually.

  1. Use Edit or Add product above.
  2. Click Download updated catalogue.js.
  3. Open the Huon Prints review branch on GitHub. Choose Add file → Upload files, and upload the downloaded catalogue.js into the root folder (alongside index.html). Confirm that you're replacing the existing catalogue file and commit to the review branch.
  4. For new photographs, upload the original JPG or PNG files into assets/products on the same review branch. Type the exact filename in the product editor.
  5. Download a fresh review-branch ZIP and check the website before considering any publication.

Important: The image chooser below previews local photos but cannot upload them to GitHub automatically. Avoid entering customer details or private information in product descriptions.
